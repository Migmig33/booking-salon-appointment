Design a complete, high-fidelity **customer-facing website and online appointment booking experience** for **TJ Hair Salon**, located in Bayside, Queens, New York.

This design is ONLY for salon customers.

Do NOT create:

* Admin dashboard
* Owner interface
* Staff management dashboard
* Backend settings
* Appointment management interface

Those will be designed separately later.

The purpose of this design is to show what a customer sees from discovering TJ Hair Salon to successfully booking an appointment.

# Visual Direction

Create an upscale but approachable salon aesthetic.

The design should feel:

* Modern
* Elegant
* Warm
* Professional
* Minimal
* Fashion-forward
* Local and welcoming
* Highly visual

Avoid making the salon look excessively expensive or intimidating.

## Color Palette

Use:

* Warm cream / off-white backgrounds
* Soft beige / taupe secondary surfaces
* Deep charcoal / near-black text
* Subtle bronze or muted gold accent

Use accent colors primarily for:

* Primary buttons
* Selected services
* Selected dates
* Selected time slots
* Booking progress
* Small decorative details

Avoid:

* Bright pink
* Neon colors
* Excessive gradients
* Generic SaaS styling
* Excessive glassmorphism

# Typography

Use an elegant editorial serif or stylish display font for major headings.

Pair it with a clean modern sans-serif font for:

* Navigation
* Body copy
* Buttons
* Forms
* Booking interface

Typography should feel premium while remaining easy to read.
